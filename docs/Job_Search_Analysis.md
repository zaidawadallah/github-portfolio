## 4. What employers ask for most
Across the postings, the most repeated requirements were:
1. **Bachelor's degree in CS, IT or a related field** — I will meet this in December 2026.
2. **SQL / relational databases** (SQL Server named directly) — a gap for me.
3. **A mainstream application stack** — C#/.NET or Java — a gap; my strongest languages are JavaScript and Python.
4. **Troubleshooting and customer communication** — a strength from running dispatch and customer service.
5. **Networking: TCP/IP, network hardware, security** — partial strength from coursework; no certification yet.
6. **Cloud certification (AWS) preferred** for systems roles — a gap.
7. **Testing / QA** — partial strength; I write unit tests for my projects.
